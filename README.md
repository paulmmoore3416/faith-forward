## 🎖️ Our Mission
**Faith Forward** is a veteran-owned and operated 501(c)(3) non-profit organization based in St. Louis, Missouri. Founded by a combat veteran who conquered homelessness, addiction, and incarceration, we serve as the "Last Tactical Mile" bridge between veterans in crisis and the resources they earned.

We provide a direct map to housing, employment, medical care, and food stability, while fostering a community of brotherhood and spiritual resilience.

---

## 🎒 Current Operations: Winter Survival Backpack Drive
We are currently in a high-priority collection phase for our **Annual Winter Survival Backpack Drive**. We collect tactical backpacks and fill them with life-saving supplies for unhoused veterans living on the streets of St. Louis.

**Needed Supplies:**
- Tactical/Sturdy Backpacks
- Thermal Socks & Beanies
- Hygiene Kits
- Non-perishable protein-dense food
- Hand warmers

## 🛠️ Technology & Architecture
This platform is a high-performance, modern web application built to serve the veteran community reliably and securely.

- **Stack:** TypeScript, Tailwind CSS v4, Vite.
- **Content:** Dynamic St. Louis resource hub (15-mile radius).
- **Inspiration:** Integrated Daily Scripture & Reflection engine.
- **Deployment:** Multi-stage Dockerized environment (Nginx).

### 🚀 Getting Started
To run this platform locally or on a server:

```bash
# 1. Clone the repository
git clone https://github.com/[your-username]/Faith-Forward.git

# 2. Build and launch with Docker
docker-compose up -d --build
```
